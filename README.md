# LLM Quantization Calculus Report Code

Python code, reproducible outputs, and a Streamlit visualization app for the report:

> MSE·MAE·RMSE 기반 LLM 양자화 오차와 메모리 효율의 변화율 분석

This repository contains only the Python simulation/web-visualization code used for the report. School HWPX templates, filled HWPX files, and HWPX build automation scripts are intentionally not included.

## Included files

- `scripts/llm_quantization_experiment.py`  
  Generates synthetic LLM-like weights, applies uniform quantization, computes MSE/MAE/RMSE/NRMSE, interval average rates of change, marginal efficiency, and an optional exponential MSE fit.
- `streamlit_app.py`  
  Interactive web UI for changing simulation parameters and visualizing the error/memory trade-off.
- `quantization_results/`  
  CSV tables and SVG figures generated by the script.

## Run the Streamlit app

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run streamlit_app.py
```

The app provides:

- bit-width sliders/selectors
- synthetic weight distribution visualization
- MSE/MAE/RMSE/NRMSE charts
- NRMSE threshold lines
- relative memory chart
- interval average-rate and marginal-efficiency chart
- uniform quantization step-function visualization
- downloadable CSV tables

## Reproduce static outputs

```bash
python scripts/llm_quantization_experiment.py
```

The script writes outputs to `quantization_results/`:

- `bit_metrics.csv`: bit-width별 error/memory metrics
- `interval_metrics.csv`: 구간별 평균변화율과 한계 효율
- `fit_metrics.csv`: 지수감소 근사와 도함수 해석용 값
- `summary.md`: 자동 요약
- `fig_*.svg`: 보고서에 사용한 그래프

## Streamlit Community Cloud deployment

To make the app directly viewable in a browser:

1. Go to <https://share.streamlit.io/>.
2. Connect this GitHub repository.
3. Set the main file path to `streamlit_app.py`.
4. Deploy with the default `requirements.txt`.

No secrets or API keys are required.

## Scope

This is a simplified simulation, not a benchmark of real LLM perplexity or task accuracy. The goal is to explain how quantization bit-width changes error and memory efficiency using Calculus I concepts.

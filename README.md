# LLM Quantization Calculus Report Code

Python code, reproducible outputs, and a deployed Streamlit visualization app for the report:

> MSE·MAE·RMSE 기반 LLM 양자화 오차와 메모리 효율의 변화율 분석

## Live app

Open the interactive visualization here:

<https://llm-q-calculus-sd.streamlit.app/>

The app lets readers change the simulation conditions and immediately recalculate the error/memory trade-off.

## Scope and privacy

This repository contains only the Python simulation/web-visualization code used for the report. School HWPX templates, filled HWPX files, PDF exports, student-identifying forms, and HWPX build automation scripts are intentionally not included.

This is a simplified educational simulation, not a benchmark of real LLM perplexity, generation quality, or task accuracy. The goal is to explain how quantization bit-width changes error and memory efficiency using Calculus I concepts.

## Included files

- `scripts/llm_quantization_experiment.py`  
  Generates synthetic LLM-like weights, applies uniform quantization, computes MSE/MAE/RMSE/NRMSE, interval average rates of change, marginal efficiency, and an optional exponential MSE fit.
- `streamlit_app.py`  
  Interactive web UI for changing simulation parameters and visualizing the error/memory trade-off.
- `quantization_results/`  
  CSV tables and SVG figures generated by the script.

## App features

- bit-width selectors for comparing quantization levels
- sliders for sample count `N`, synthetic weight standard deviation `σ`, clipping range, seed, and NRMSE thresholds
- synthetic weight distribution visualization
- MSE, MAE, RMSE, and NRMSE charts
- NRMSE threshold lines for practical/stable/very-precise interpretation
- relative memory chart based on `M_rel(b)=b/16`
- interval average-rate chart for `ΔMSE/Δb`
- marginal-efficiency chart for MSE reduction per additional relative-memory unit
- uniform quantization step-function visualization
- downloadable CSV tables

## Run locally

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Reproduce static outputs

```bash
python scripts/llm_quantization_experiment.py
```

The script writes outputs to `quantization_results/`:

- `bit_metrics.csv`: bit-width별 error/memory metrics
- `interval_metrics.csv`: 구간별 평균변화율과 한계 효율
- `fit_metrics.csv`: 지수감소 근사와 도함수 해석용 값
- `summary.md`: 자동 요약
- `fig_*.svg`: 보고서에 사용한 그래프

## Deployment

The current app is deployed on Streamlit Community Cloud:

<https://llm-q-calculus-sd.streamlit.app/>

To redeploy or fork it:

1. Go to <https://share.streamlit.io/>.
2. Connect this GitHub repository or a fork.
3. Set the main file path to `streamlit_app.py`.
4. Deploy with the default `requirements.txt`.

No secrets or API keys are required.

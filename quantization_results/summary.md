# LLM 양자화 모의 실험 결과 요약

## 보고서 제목

**MSE·MAE·RMSE 기반 LLM 양자화 오차와 메모리 효율의 변화율 분석**

## 실험 설정

- 모의 가중치 개수: `100000`
- 가중치 분포: `W ~ N(0, 1.0^2)`, 분석 범위 `-3.0` ~ `3.0`
- 실험 bit: `2, 3, 4, 6, 8, 16`
- 안정적 사용 가능 기준: `NRMSE ≤ 0.05`
- 실용 후보 기준: `NRMSE ≤ 0.15`
- clipping 비율: `0.301%`

## 핵심 지표

- `MSE(b) = (1/N)Σ(w_i-q_i)^2`
- `MAE(b) = (1/N)Σ|w_i-q_i|`
- `RMSE(b) = √MSE(b)`
- `NRMSE(b) = RMSE(b)/σ_W`
- `M(b)=Nb`, 상대 메모리는 `b/16`
- 한계 효율: `η=(L(b1)-L(b2))/(M(b2)-M(b1))`

## 자동 해석

- `NRMSE ≤ 0.05` 기준을 처음 만족한 bit는 **6bit**이다.
- MSE 기준 한계 효율이 가장 큰 구간은 **2->3bit** 구간이다.
- 단, 한계 효율이 크다고 해서 절대 오차가 충분히 작은 것은 아니므로, NRMSE 기준과 함께 판단해야 한다.
- 따라서 보고서 결론에서는 `절대 오차 기준을 만족하는 최소 bit`와 `추가 bit의 한계 효율 감소`를 함께 해석하는 것이 좋다.

## 지수감소 근사

- `MSE(b) ≈ 4.318386 · exp(-1.416203b)`
- 로그 공간 R²: `0.999449`
- bit 수는 실제로 이산적이므로, 본문에서는 구간별 평균변화율을 중심으로 쓰고 도함수 해석은 심화 해석으로만 사용하는 것이 안전하다.

## 생성 파일

- `bit_metrics.csv`: bit별 MSE/MAE/RMSE/NRMSE/메모리
- `interval_metrics.csv`: 구간별 평균변화율/한계효율
- `fit_metrics.csv`: 지수감소 근사와 도함수 해석용 값
- `fig_*.svg`: 보고서 삽입용 그래프
